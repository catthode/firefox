## Description

From CRT to OLED.

Catthode gives Firefox a warm, high-contrast dark interface built around true-black surfaces and nostalgic phosphor-inspired accents. It themes horizontal and vertical tabs, the toolbar and address field, menus and popups, sidebars, and the new-tab page.

## Notes for reviewers

Catthode is a static WebExtension theme. It contains no scripts, permissions, data collection, external requests, or minified code. The entire functional package is the submitted `manifest.json`; public source and validation configuration are available at https://github.com/catthode/firefox.

The theme was tested in a disposable Firefox 155.0.1 profile on macOS. Horizontal and vertical tabs, toolbar fields, the application menu, sidebar UI, and the new-tab page were inspected before preparing this submission.
